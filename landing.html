Core: Grammar Architecture

Formal Context-Free Grammar Design in ANTLR4

1. Hierarchy Design

We use a strict recursive descent structure. The `program` rule acts as the entry point, delegating to `classDef` for Java or a sequence of `stmt` for Python.

/* java2py.g4 */
program: classDef EOF;
classDef: PUBLIC CLASS ID '{' classBody '}';
methodDef: PUBLIC STATIC javaType ID 
          '(' param? ')' block;

2. Command DSL

We built a Natural Language interface by defining a command grammar for user intent.

/* command.g4 */
command: verb noun* target?;
verb: ('show' | 'translate' | 'save');
target: source TO target_lang;

3. Lexer vs. Parser & Precedence

Lexical Sensitivity

Python's indentation is handled by the `NL` rule, preserving whitespace context for the parser, whereas Java's Lexer is designed to be whitespace-agnostic.

/* Python Lexer Snippet */
NL: ('\r'? '\n' [ \t]*);
WS: [ \t]+ -> skip;

Operator Precedence

By structuring rules from `logicExp` down to `atom`, we enforce that Multiplication happens before Addition without needing explicit parenthesis.

/* Recursive Expression Hierarchy */
exp: logicExp;
logicExp: compExp (op=('&&'|'||') compExp)*;
addExp: mulExp (op=('+'|'-') mulExp)*;
mulExp: unaryExp (op=('*'|'/') unaryExp)*;

Visitor Pattern & Type Inference

Our translator uses the **Visitor Pattern** to decouple the translation logic from the parse tree. The **Type Inference Engine** is the most complex part, dynamically determining if a Python variable should be an `int`, `double`, or `String` in Java by analyzing the Abstract Syntax Tree (AST).

  • AST Walk: Context-aware traversal.
  • Type Guessing: Dynamic → Static mapping. 
# py2javaVisitor.py Snippet
def inferType(self, ctx):
    if ctx.STRING(): return "String"
    if ctx.NUMBER(): return "int"
    if ctx.FLOAT(): return "double"
    return "Object"
