Python → Java Test Case 4 — For Loop with range()

Input (Python) · grammar: py2java.g4

def printNumbers():
    for i in range(1, 4):
        print(i)

if __name__ == "__main__":
    printNumbers()

Output (Java)

public static int printNumbers() {
    for (int i = 1; i < 4; i++) {
        System.out.println(i);
    }
}
public static void main(String[] args) {
    printNumbers();
}

visitForStmt + visitRangeExp Unpacks range(1,4) args → emits for (int i = 1; i < 4; i++)
visitMainStmt MAIN is a composite lexer token matching __name__ == "__main__" → emits main(String[] args)
NL token (py2java.g4) Captures \n + whitespace. The block rule uses it to delimit scope — no braces needed.
Java → Python Test Case 4 — Method Call, Return & Logical Operators

Input (Java) · grammar: java2py.g4

public class MyClass {
    public static int add(int a, int b) {
        return a + b;
    }
    public static void main(String[] args) {
        int result = add(5, 3);
        System.out.println(result);
    }
}

Output (Python)

def add(a, b):
    return (a + b)
if __name__ == '__main__':
    result = add(5, 3)
    print(result)

visitMethodDef — main detection If javaType=VOID AND ID="main" → emit if __name__ == '__main__': instead of def main()
visitAddExp — precedence addExp is nested inside logicExp→compExp, so a+b is correctly evaluated before any comparison. Wraps result in ().
visitAsg — type erasure Java's int result = ... → Python's result = .... The javaType node is parsed but discarded by the visitor.
visitAtom — function call atom: ID '(' exp* ')' matches add(5,3). The visitor recurses into each exp argument and joins them with , .
